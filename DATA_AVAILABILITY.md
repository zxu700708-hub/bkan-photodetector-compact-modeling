# Data and code availability 建议文本

## 当前代码发布候选

```text
The source code, canonical TCAD-derived task tables, grouped data partitions,
frozen predictions, symbolic models, Verilog-A implementation, and hash-bound
verification materials supporting this study are versioned at
https://github.com/zxu700708-hub/bkan-photodetector-compact-modeling,
release artifact-v2026.08.31-rc10. Commercial TCAD and Cadence Spectre software
are not redistributed; the repository provides exported data, executable input
decks where licensing permits, software-version information, provenance
manifests, and verification reports.
```

## 长期归档后使用

获得 DOI 并生成发布压缩包后，可改为：

```text
The data, source code, experiment configurations, grouped data partitions,
frozen predictions, symbolic models, Verilog-A implementation, and verification
materials supporting this study are archived at [ZENODO DOI]. The archived
release is artifact-v2026.08.31-rc10 and its archive SHA-256 is [ARCHIVE SHA-256].
Commercial TCAD and circuit simulators are not redistributed.
```

只有在 Zenodo DOI 和压缩包 SHA-256 实际生成后才能替换方括号字段。若投稿仍采用双盲审稿，不应在匿名稿中使用能够关联作者身份的账号 URL，应改用期刊允许的匿名只读链接。
