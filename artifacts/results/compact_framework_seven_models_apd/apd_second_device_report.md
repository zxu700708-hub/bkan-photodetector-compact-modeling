# APD 7 模型结构分组比较

以 `structure_group_id` 为独立划分单位，在 APD 数据上训练和测试各模型。
共 6 个任务、7 个模型、10 个随机种子。
电流和倍增增益的 RMSE 在 log10 空间计算；两个电压任务的 RMSE 单位为 V。均值 ± 标准差描述不同划分的结果。
全部模型使用相同的训练与测试结构；标准化只拟合训练集。
GMLS-adapted、AutoPINN-adapted、Curve-LUT-PCHIP 是针对本数据接口的事后方法适配或实现，不等同于原论文源码复现，其比较按探索性证据解释。
原有预测来源：`<REPO_ROOT>/artifacts/results/compact_framework_eight_models_apd`。
